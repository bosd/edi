This module adds purchase order creation from Punchout shopping carts.

When a user browses a supplier's punchout catalog and returns with a
shopping cart, this module allows creating a purchase order directly
from the cart data.

Features:

- Link punchout sessions to purchase orders
- Automatic product creation from cart items
- Smart buttons to navigate between sessions and orders
